# '함께 나온 개념' 표 줄이기 실험 (2026-11-13)

사용자 요청(11-13): 프롬프트가 계속 들어와도 저장 공간·메모리에 무리가 가지 않게. 실험부터 하고 결과를 보고 결정한다.

- 실행: `python experiments/2026-11-13-cooc-slim/run.py` (개념 차트 서버가 켜져 있어야 한다. 공부 목록 판정을 API로 받는다)
- 실제 저장 파일은 읽기 전용으로 열어 임시 폴더에 사본을 만들고, 사본만 쓴 뒤 지운다. `results.json`에는 숫자만 있다.
- 확인: 날짜순으로 다시 쌓은 표가 실제 표와 줄 하나까지 같다 (`rows_differing: 0`). 관련 개념 규칙은 실제 노트 API와 30개 중 30개가 같다.

## 읽는 법

- B·C(답변마다 개수 제한)는 관련 개념이 거의 다 바뀐다. 쓰지 않는다.
- D·F는 판정에 기대므로 실제 동작을 이 실험으로 보장할 수 없다.
- E는 판정과 무관하고, 줄 수의 상한이 '개념 수 × K'라 답변이 늘어도 제곱으로 커지지 않는다. 대신 정리 전까지는 큰 답변 하나가 한때 많은 줄(최대 87,912)을 쓴다.
- 이 표는 원래 기록(인박스)에서 다시 만들 수 있는 값이다 (`--rebuild`).
- 6일치 자료라 앞으로의 증가 속도는 재지 않았다.
