# 공부 목록의 쉬운 낱말 — 분류기 켜기와 대문자 줄임말 (11-14)

사용자: "너무 터무니없는 쉬운 단어들도 저기 박히니까 … 이걸 일일이 사용자가 다 골라야돼? 불편해"

## 1. 개발 서버에 개념 분류기가 꺼져 있었다
`python dev.py app`은 분류기(D9, 기준점 0.97)를 켜지만, 이날 서버는 `kit/serve.py`를 직접 실행해 꺼져 있었다.
그래서 예전 판정(LLM 혼자 인정)으로 okay·sky·your·could 같은 영어 일상어가 공부 목록에 들어왔다.

`python experiments/2026-11-14-clf-on/run.py` (공부 목록 591개, 사람 판단 84개는 그대로):
- 분류기가 판정하는 371개 중 182개가 기준점 아래 → 공부 목록에서 빠짐 (영어 일상어 대부분)
- 빠지는 것 중 버전·로그인·업데이트·백업은 사용자가 이전에 '아님'으로 표시한 낱말 (D9)

조치: 서버를 분류기를 켜서 다시 실행 (설정·코드 변경 없음, D9 결정대로). 분류기가 더 넓게 인정하는 개념도 들어와 목록은 605개.

## 2. 대문자 줄임말 (BY·KR·CH·OH·OIL)
2~6자 대문자는 규칙만으로 통과(accept)해서 분류기를 거치지 않는다.
`run.py --caps`: 이 73개를 분류기에 맡기면 —
- 빠짐(21): BY VS ID KR MIT GUIDE PC OH UX TALN LOG PM CC MV RIG CH LS OIL EXAONE THYNK IBM
- 남음(52): CO SA MET CROSS도 남고, PC·UX·IBM은 빠진다

결과가 섞여서 **바꾸지 않았다** (사용자 결정 필요). 대신 화면에 '한 번에 정리하기'(여러 낱말을 골라 한꺼번에 아니에요)를 넣었다.

결과 파일(`results.json`, `caps_results.json`)은 내 대화의 개념 이름이 들어 있어 커밋하지 않는다.
