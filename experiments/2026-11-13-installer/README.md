# 윈도우 설치 파일 실험 (2026-11-13)

사용자 요청(11-13): 다른 프로그램처럼 exe를 누르면 설치 마법사가 뜨고 바로 쓸 수 있게, 서비스 설정을 모두 넣고, 보안 프로그램에 걸리지 않게. 맥은 맥 PC에서 이어서.

## 만든 것 (`installer/`)

- `build.py`: python.org 내장용 파이썬 3.13.15 + 서비스 패키지 4개(버전 고정: kiwipiepy 0.24.1, kiwipiepy_model 0.24.0, trafilatura 2.3.1, pywebview 6.2.1) + 서비스 파일(kit·분야 사전·chat·app·extension) → Inno Setup으로 컴파일. 대화 기록 DB·인박스는 넣지 않는다(검사 포함).
- `thynk.iss`: 한국어 마법사. 관리자 권한 없이 사용자 폴더(`%LOCALAPPDATA%\Programs\THYNK`)에 설치. 고를 것: 바탕화면 아이콘(기본 켬), 윈도우 시작 때 기록 받기 켜기(기본 끔), Claude Code 연결(기본 끔), AI 받기(기본 끔, ollama.com 공식 설치 파일을 받아 그 설치 화면을 띄운 뒤 모델 받기).
- `launcher.pyw`: 아이콘이 여는 실행기. 서버를 창 없이 켜고 WebView2 앱 창을 연다. 창을 닫으면 켠 서버를 끈다(시작 때 켜기를 골랐으면 개념 차트 서버만 남김).

## 확인하지 못한 것 / 남은 것

- **스마트스크린 경고:** 코드 서명이 없어 인터넷에서 받은 설치 파일은 '알 수 없는 게시자' 경고가 뜰 것으로 본다(서명 인증서 없음, 직접 확인 안 함). 없애려면 코드 서명 인증서가 필요하다(비용·절차 확인 안 함). Defender 검사는 통과.
- 마법사 화면을 사람이 눌러 보는 시험(조용한 설치로만 시험), AI 받기(약 6GB, 이 PC에는 이미 있어 받지 않음), Claude Code 연결 옵션(이 PC의 실제 훅을 바꾸므로 시험 안 함), 윈도우 시작 때 켜기.
- 다른 PC(파이썬·WebView2·.NET이 없는 깨끗한 윈도우)에서의 시험.
- 맥용(.dmg)은 맥에서 만들어야 한다.
