## 0. 무엇을 알고 싶었나

수준선(D12)은 "이 낱말이 나에게 어려운가"를 점수로 매겨야 한다. 후보 데이터 세 가지가 그 점수에 쓸모가 있는지 본다.

| 후보 | 출처 · 라이선스 | 기대한 역할 |
|---|---|---|
| 국립국어원 한국어 학습용 어휘 목록 (2003) | korean.go.kr, 공공누리 제1유형 | 등급 A·B(기초어)는 선 아래로 |
| Leipzig 한국어 뉴스 2022 (10만 문장) | wortschatz-leipzig.de, CC BY 4.0 (검색 결과 기준, 원 페이지 재확인 필요) | 일상에서 흔한 낱말은 선 아래로 |
| wordfreq 3.1.1 (영어) | PyPI, 코드 Apache-2.0 (pip 메타데이터 확인), 데이터 CC BY-SA 4.0 | 흔한 영어 낱말(Design·Export)은 선 아래로 |

**한계를 먼저:** 수준별 정답이 없다(WORKSHEET 2절). 그래서 대리 과제로 잰다. 대리 과제 숫자는 "신호가 일상어와 전문어를 가르는가"이지 "사용자가 아는가"가 아니다.

## 1. 데이터 받기 (임시 폴더, 레포에 넣지 않음)

| 파일 | 크기·내용 | 확인 |
|---|---|---|
| 학습용 어휘 목록 `vocab.txt` | cp949 탭 구분 (순위·단어·품사·풀이·등급) | sha256 `3b49681f…85064` = `lexicons/basicvocab.py`에 고정된 값과 같음 |

Leipzig API(`availableCorpora`)는 한국어 목록을 돌려주지 않아 내려받기 주소를 직접 확인했다.

## 2. 전처리

1. **학습용 어휘:** 품사 `명`만, 표기 끝 숫자(동음이의 번호) 제거 → **명사 3,266개 (A 479 · B 1,152 · C 1,635)**.
2. **뉴스 빈도:** Leipzig가 주는 빈도표는 어절 단위라 조사가 붙는다(`과적합을`). 그래서 문장을 Kiwi로 다시 나눠 명사(NNG·NNP)와 영어(SL, 소문자)만 셌다 → **명사 토큰 1,177,416개, 서로 다른 명사 57,898개**.
3. **점수 눈금:** wordfreq와 같은 zipf = log10(10억 낱말당 빈도). 뉴스에 한 번도 안 나온 낱말은 +1 보정으로 **2.93**이 된다 (아래 '3.0 기준'은 사실상 '한 번이라도 나왔나').
4. **대리 과제 집합**
   - 기술 용어: `kit/data/tech_terms.txt`에서 한글만, 2~8자, 학습용 어휘와 겹치는 것 제외 → **1,389개**
   - 기초어: 학습용 어휘 A등급 명사 → **479개**
5. **영어:** `tech_terms.txt`의 영어 낱말(2~20자, 소문자) **1,713개**의 wordfreq 점수.
6. **실제 답변:** 이 Mac의 `~/.claude/projects/*/*.jsonl`에서 assistant 글 중 한국어가 있고 200자 넘는 것(최대 400개) → **152개** (재실행 때 153개, 이 대화가 늘어서). 원문은 출력·저장하지 않음.

## 3. 측정과 중간 결과

### 3-1. 뉴스 빈도가 기술 용어와 기초어를 가르나

- AUC(희귀할수록 어렵다) = **0.958**
- 뉴스에 한 번도 안 나옴: 기술 용어 **81.1%**, 기초어 **2.9%**

| 남기는 기준 (zipf 미만) | 기술 용어 남음 | 기초어 남음 |
|---|---|---|
| 3.0 (한 번도 안 나옴) | 81.1% | 2.9% |
| 3.5 | 88.0% | 5.4% |
| 4.0 | 93.4% | 12.9% |
| 4.5 | 96.9% | 33.0% |

중간에 본 것: **뉴스에 흔한 기술 용어** 상위 — 페이스북, 지수, 유튜브, 인증, 주석, 멤버, 스마트폰, 요소, 구글, 차단, 사이트, 네이버, 표명, 비전, 구현, 넷플릭스, 이벤트, 블록체인, 확률, 클라우드, 프레임, 공백, 상속, 변수, 회로.
→ 브랜드 이름(유튜브·구글)은 내려가도 되지만, **변수·상속·확률·클라우드·인증**은 초보에게 공부할 개념이다. 빈도만으로 자르면 이것들이 숨는다.

**뉴스에 드문 기초어** — 구월, 부모님, 사월, 선생님, 지우개, 공중전화 … (월 이름·높임말·생활 낱말)
→ 빈도만 쓰면 이런 쉬운 낱말이 '어려움'으로 올라온다. 학습용 어휘 등급이 이 빈틈을 막는다.

### 3-2. 학습용 어휘 등급

대리 과제의 기초어를 이 목록에서 뽑았으므로 AUC를 재면 1.0이 나온다. 공정한 측정이 아니라 재지 않았다. 확인한 것은 범위뿐이다: 명사 3,266개 — 기초어만 담은 목록이라 '아래로 내리는' 데만 쓸 수 있다.

### 3-3. wordfreq (영어)

| zipf 이상 | 영어 기술 용어 비율 |
|---|---|
| 3.0 | 30.5% |
| 4.0 | 12.4% |
| 4.5 | 6.1% |
| 5.0 | 2.3% |

흔한 쪽 상위: go, here, ever, number, name, mean, music, power, head, job, service, post, information, mind, death, understand, class, question, turn, media, type, self, rest, site, security.
→ 앞쪽(go·here·ever)은 기술 용어 목록 자체의 잡음이라 내려가는 게 맞고, **class·type·security·service**는 개발 개념이라 내려가면 안 된다. 기준 4.0이면 12%가 숨는다.

### 3-4. 실제 Claude Code 답변에 두 규칙을 걸어 보기

규칙(예시): 학습용 어휘 A·B → 0단계, 뉴스 zipf ≥ 4.0 → 1단계, 나머지 → 2단계.

| | 답변당 명사 | 남는 비율 |
|---|---|---|
| 아무것도 안 뺌 | 72.0개 | 100% |
| 기초어(A·B)만 빼기 | 약 46개 | 64.3% |
| 기초어 + 뉴스에 흔한 말 빼기 | 약 9개 | 12.3% |

중간에 본 단계별 낱말(자주 나온 순, 개인 낱말 제외):
- 0단계(기초어): 확인, 파일, 필요, 문제, 결과, 시작, 정리, 내용, 방법, 이름 — 빼도 되는 말들
- 1단계(뉴스에 흔함): 화면, 실행, 연결, 설정, **서버, 데이터, 코드**, 기록, 설치, 저장 — 초보에게는 개념일 수 있는 말이 섞임
- 2단계(남음): 로그, 폴더, 업로드, 부팅, 브라우저, 펌웨어, 시리얼, 커밋 … — 기술 용어가 많지만 폴더·예시·시간표 같은 생활 낱말도 남음

## 4. 결론 (사용자 결정 전 제안)

1. 학습용 어휘 등급은 **모든 수준에서 바닥 거르기**로 쓸 만하다(쉬운 말만 내린다, 잘못 내리는 위험이 작다).
2. 뉴스 빈도는 **수준 손잡이**로: 초보 수준에서는 끄고, 실무자·연구자 수준에서 켠다. 켜면 답변당 낱말이 72 → 9개 수준으로 준다.
3. wordfreq는 영어 일상어를 거르는 데 효과가 있지만 class·type 같은 개발 개념도 내리므로, 기술 용어 사전에 있는 낱말은 빼고 적용해야 한다(아직 안 재 봄).
4. 어느 것도 "사용자가 아는가"를 잰 것이 아니다. 수준선을 켠 뒤 '알아요/몰라요'를 모아 다시 잰다.

## 6. 실제 서버 판정 위에 얹어 보기 (같은 날 15:00~15:20)

- **방법:** 이 Mac의 Claude Code 대화(질문 156 · 답변 154)를 훅 형식 그대로 임시 인박스로 만들고(`make_inbox.py`, 키 가림), 실제 서버(`kit/serve.py`, 임시 DB, 포트 8777, `qwen3:4b` + SearXNG)를 띄워 약 20분 판정시켰다. 그 결과(`/api/study/concepts`)에 수준선 규칙을 얹었다(`apply_level.py`). 서버 코드는 바꾸지 않았다.
- **판정 진행:** 낱말 2,659개 중 606개 판정(AI 판정 1건 약 9초, 전부 하려면 5시간 이상). 순위 상위 100개 중 80개, 상위 200개 중 130개.
- **규칙:** 초보 = 학습용 어휘 A·B 아래로 · 중급 = A·B·C 아래로 · 실무자 = 중급 + 뉴스 zipf ≥ 4.0 아래로(개발 용어 사전에 있으면 남김).

| | 지금 공부 목록 | 초보 | 중급 | 실무자 |
|---|---|---|---|---|
| 공부 목록 개념 수 | 222 | 222 | 222 | 204 (−8%) |
| 상위 200위 안 | 19 | 19 | 19 | 14 |
| 답변당 개념 (100답변) | 4.43 | 4.43 | 4.43 | 3.63 |

- **알게 된 것:** 학습용 어휘 등급으로는 하나도 빠지지 않는다. 서버의 개념 관문이 이미 기초어(파일·저장·확인)를 걸러 내기 때문이다. 수준선이 바꾸는 것은 실무자 쪽뿐이고, 빠진 18개는 모두 뉴스에 흔한 영어 약어다: IP, AI, ID, DB, VS, QR, PC, USB, LED, CP, CPU, SW, OLED, IoT, MVP, LIFE, NFC, ESG.
- **뜻:** 사람마다 다른 '아는 낱말'은 사전·빈도로는 거의 갈리지 않는다(관문 뒤에 남은 낱말은 대부분 전문어). 개인차를 반영하려면 사용자의 '알아요' 기록이 주된 손잡이다.
