THYNK 설치 안내

AI와 나눈 공부 대화를 개념 노트로 모아 주는 프로그램이에요. 모든 기록은 내 컴퓨터에만 저장돼요.

경고 창이 떠도 괜찮아요. THYNK는 아직 유료 '코드 서명'을 하지 않은 프로그램이라, Windows가 처음 보는 프로그램이라고 알려 줘요. 설치 파일은 Microsoft Defender 검사에서 위협이 발견되지 않았어요. 관리자 권한도 요구하지 않아요.

  1. 설치 파일 받기

    {{FILE}} (약 610MB)을 받아요. 브라우저가 "흔히 다운로드되지 않는 파일"이라고 하면 …(더 보기) → 유지를 눌러요.

  2. “Windows의 PC 보호”가 뜨면 추가 정보 → 실행

    파란 창이 뜨면 왼쪽 아래 글자 추가 정보를 누르고, 새로 생긴 실행 단추를 눌러요. 게시자에 “알 수 없는 게시자”라고 나오는 게 정상이에요.

  3. 설치 마법사에서 고르기

    ‘다음’을 누르다가 추가 작업 선택에서 필요한 것만 고르면 돼요. 모르면 기본값 그대로 두세요.

    바탕화면 아이콘기본 켬바탕화면에서 THYNK를 열 수 있어요.
    윈도우를 켤 때 켜기기본 끔웹 브라우저(claude.ai)의 답변을 받으려면 켜 두세요. 메모리를 약 50MB 써요. 끄면 THYNK 창을 연 동안만 받아요.
    Claude Code 연결기본 끔Claude Code를 쓰는 경우에만 고르세요. 대화가 저절로 모여요.
    쉬운 설명 AI기본 끔개념을 더 쉽게 풀어 주는 AI를 내 PC에 받아요(약 6GB, 시간이 걸려요). 없어도 출처가 붙은 설명은 그대로 나와요. 나중에 받아도 돼요.

  4. THYNK 열기

    설치가 끝나면 THYNK 열기에 체크된 채로 ‘마침’을 눌러요. 다음부터는 시작 메뉴나 바탕화면의 THYNK 아이콘을 눌러요.

    창을 닫으면 THYNK도 꺼져서 메모리를 쓰지 않아요 (‘윈도우를 켤 때 켜기’를 고른 경우만 가볍게 켜져 있어요).

  5. 지우기

    설정 → 앱 → 설치된 앱 → THYNK → 제거. 프로그램은 모두 지워지고, 내 공부 기록(사용자 폴더\.claude)은 남아요.

Mac용은 준비 중이에요. Mac용 설치 파일(.dmg)은 아직 없어요. 나오면 이 탭에 순서를 적을게요.
